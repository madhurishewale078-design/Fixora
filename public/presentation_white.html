Slide 02 • Motivation & Industry Analysis

The Problem in Traditional Home Maintenance

Critical Inefficiencies

Unnecessary Call-Out Fees

Over 35% of home appliance call-outs are triggered by trivial glitches (such as a tripped MCB breaker, clogged tap aerator, or misconfigured remote setting). Consumers pay ₹400 to ₹800 simply for a technician to flip a switch.

Opaque & Surprise Pricing

Marketplaces lack upfront diagnostic clarity. Customers are given arbitrary estimates that double upon physical arrival due to unforeseen "part replacements" and hidden labor surcharges.

Blind Technician Dispatch

Service professionals arrive without knowing the exact model, fault symptoms, or needed parts. This leads to 2 to 3 round trips to wholesale hardware stores, delaying resolution by days.

Unvetted Handymen & Security Risks

Local classified platforms offer no background checks, skill certifications, or dispute recourse when a technician damages expensive smart appliances or performs sub-standard work.

Key Takeaway: Home repairs suffer from an information asymmetry problem. Consumers lack diagnosis; technicians lack context. FIXORA Solves This Upfront ➔

Relational Database Schema (12 Entities)

3NF Normalized Schema
Core Auth

users

id, email, hashed_password, role (CUSTOMER, TECH, ADMIN), is_active, created_at

Customer Entity

user_id, full_name, phone, address, city, pincode, lat, lng

Business Core

id, customer_id, technician_id, service_id, status, total_price, scheduled_date

Audit Logging

booking_history

id, booking_id, old_status, new_status, changed_by, reason, created_at

Quality Gate

reviews

id, booking_id, rating (1-5), comment. Unique constraint ensures 1 review per booking.

Dispute System

complaints

id, customer_id, booking_id, title, description, status (OPEN, RESOLVED)

Catalog

services & categories

id, name, description, base_price, estimated_time, is_active, category_id

🛡️ Relational Integrity: Cascading foreign keys prevent orphan bookings; database unique indexes prevent duplicate reviews or fake ratings.
Slide 12 • AI Algorithms & Safety Guarantees

Deterministic DAG vs Generative LLM Comparison

Zero Hallucination Guarantee
A

Safety-First Rule DAG

Unlike generative chatbots that might hallucinate dangerous electrical advice (e.g. telling an amateur to probe an open capacitor), FIXORA uses a certified, deterministic decision graph.

✓ 100% Deterministic Reproducibility
B

Pluggable Engine Adapter

Implemented behind an abstract base class TroubleshootingEngine. This architecture allows effortless future plug-and-play switching to multimodal LLMs (e.g. Gemini Vision) while keeping safety gates active.

✓ Clean Architecture Abstraction
C

3-Tier Severity Firewall

• TIER 1 (GREEN): Safe DIY (air filter clean, reset switch).
• TIER 2 (AMBER): Conditional DIY (main MCB switched off).
• TIER 3 (RED): Mandatory Dispatch (refrigerant leak, burnt smell).

✓ Zero Consumer Risk

Slide 13 • Security & Compliance

Authentication, Authorization & OWASP Security

Enterprise Security Standard

Direct Bcrypt Password Hashing

All user passwords salted and encrypted using pure bcrypt with an adaptive work factor. No plaintext credentials ever reach logs or database records.

Stateless JWT HS256 Token Auth

Issues cryptographically signed JSON Web Tokens encoding user ID, email, and verified role with 24-hour expiration token rotation.

Strict Role-Based Access Control (RBAC)

Endpoints protected via FastAPI Dependency Injection: require_role(["ADMIN"]). Customers cannot mutate technician profiles; technicians cannot approve themselves.

SQL Injection & CORS Hardening

All database queries execute through SQLAlchemy parameterized ORM layers. Strict CORS policies block unauthorized cross-origin script executions.

✅ OWASP Top 10 Verified: Zero SQL injection vulnerabilities, strict JWT lifecycle, and CSRF protection.
